# Saman Chat — Stitch Project Brief

Status:
Approved UX/UI Core

Visual baseline:
Approved Saman Home

Product role:
- personal fitness coach
- nutrition advisor
- nutrition monitoring companion
- adaptive trainer
- recovery assistant
- conversational personal companion

Core principle:
Conversation first.
Fitness context appears only when relevant.
Personalization should be felt through relevance, not shown as a dashboard.

1. Empty / New Conversation (`screens/01-empty-state.png`)
